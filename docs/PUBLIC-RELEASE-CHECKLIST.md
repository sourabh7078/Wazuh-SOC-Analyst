# Public Repository Release Checklist

- [ ] Inspect every screenshot for passwords, API tokens, enrollment keys, private keys, QR codes, email addresses, and personal data.
- [ ] Mask internal IP addresses, domain names, usernames, hostnames, and organization information if they should not be public.
- [ ] Confirm screenshots do not expose public dashboard URLs or externally reachable management interfaces.
- [ ] Review the assessment export and confirm it is intended for public release.
- [ ] Remove credentials from command examples and configuration files.
- [ ] Verify screenshots are genuine and correspond to the described work.
- [ ] Add exact Day 1–22 notes only after matching each day to its real session.
- [ ] Recheck README and screenshot manifest after redaction.

The source archive contained screenshots and a CSV assessment export. The prepared documentation package does not include manager configuration backups, agent keys, passwords, or deployment secrets.
